🌟 1. Project Essence in Plain English

When a user carries a smartphone, the internal triaxial accelerometer (detecting acceleration and gravity) and triaxial gyroscope (detecting angular velocity) capture motion 50 times each second.

The Core Problem: Can an AI system classify human movement into 6 daily activities (Walking, Walking Upstairs, Walking Downstairs, Sitting, Standing, Laying) using only these sensor readings?

The Result: Our pipeline achieves 96.84% accuracy on 2,947 completely unseen test samples!

🔬 3. Complete End-to-End ML Pipeline

Stage 1: Exploratory Data Analysis (EDA)

  • Class Balance: Each activity represents 14% to 19% of the dataset (~1,000 to 1,400 samples each), confirming class equilibrium.
  • Static vs Dynamic Separation: Walking activities generate high kinetic acceleration variance, whereas Sitting, Standing, and Laying are governed almost exclusively by the Earth's gravitational vector.
  • Multicollinearity: High pairwise correlations (over 100 feature pairs with |r| > 0.90) established the absolute necessity for dimensionality reduction.

Stage 2: Unsupervised Learning (Clustering)

  • K-Means Optimization: We tested $k \in [2, 10]$ without using ground-truth labels. The Elbow Method (sum of squared distances) and Silhouette Score peaked at exactly $k=6$, proving that the sensor features naturally cluster into the 6 physical activities.
  • Clustering Fidelity: Adjusted Rand Index (ARI) = 0.448; Normalized Mutual Information (NMI) = 0.562.
  • DBSCAN Density Tuning: Evaluated using a 5-NN sorted distance graph to locate the density knee point ($\varepsilon = 15.0$, `min_samples` = 5), successfully isolating sensor noise from dense activity manifolds.

Stage 3: Dimensionality Reduction (Feature Selection vs PCA)

Configuration Feature Count 5-Fold CV Accuracy Bandwidth Reduction
Full Baseline Space 561 features 96.25% 0% (Full baseline)
SelectKBest (ANOVA F-test) 100 features 95.80% 82.2% reduction
PCA (95% Variance) 102 components 95.40% 81.8% reduction

Key Takeaway: Discarding over 82% of sensor features reduces accuracy by less than 0.5% while accelerating prediction speed by ~5× for low-power mobile hardware.

Stage 4: Supervised Learning Benchmark

  • Gaussian Naive Bayes (78.3%): Struggled because it assumes conditional independence among features, which is violated by correlated sensor channels.
  • Decision Tree (87.2%): Prone to variance and orthogonal axis cuts.
  • Weighted KNN (92.4%): Inversely weights nearest neighbors by Euclidean distance ($1/\text{distance}$), significantly outperforming standard uniform KNN ($k=5$ at 91.5%).
  • Random Forest (93.8%): Bagging ensemble of 100 decorrelated trees reducing variance.
  • SVM with RBF Kernel (96.54% — Best Individual Model): The Radial Basis Function kernel projects the continuous curved motion vectors into infinite-dimensional Hilbert space to find the optimal separating hyperplane.

Stage 5: Ensemble Architectures (Hard vs Soft Voting)

  • Hard Voting (96.71% Test Accuracy): Plurality majority voting where each base estimator casts one discrete integer class vote.
  • Soft Voting (96.84% Test Accuracy — CHAMPION 🏆): Averages the calibrated posterior class probabilities across models. Highly confident predictions override marginal guesses, yielding the highest Macro F1-Score of 96.88%.

❓ 5. Professor's Expected Viva Questions & Model Answers

Q1: Why did you choose this dataset over common ones like Iris or Titanic?
"Sir, benchmark lab datasets often have fewer than 10 features. The UCI HAR dataset features 561 variables across 10,299 samples, which allowed us to rigorously examine the Curse of Dimensionality, evaluate filter selection against PCA compression, and observe how high-dimensional geometry impacts distance-based and kernel methods."
Q2: Why did SVM with an RBF Kernel outperform Decision Trees and Naive Bayes?
"Sir, Naive Bayes assumes independent features, which fails because triaxial sensors are correlated. Decision Trees make axis-parallel rectangular splits that struggle with smooth continuous curves. The SVM RBF kernel projects the 561-D data non-linearly to construct a maximum-margin hyperplane."
Q3: What is the fundamental difference between Hard and Soft Voting?
"Sir, Hard Voting is simple majority rule where each model casts one label vote. Soft Voting averages the predicted class probabilities across all models ($\arg\max \sum P_i(y|x)$). Soft Voting won because a 98% confident prediction by SVM appropriately outweighs split votes from less confident classifiers."
Q4: How did you determine that k=6 is optimal in K-Means without looking at the labels?
"Sir, in Notebook 02, we hid all labels and ran K-Means for $k \in [2, 10]$. Both the Inertia Elbow bend and the Silhouette Score peaked at $k=6$, proving that the physical sensor signals naturally cluster into 6 distinct biomechanical movement patterns."
Q5: Why did you use Stratified K-Fold instead of standard K-Fold?
"Sir, standard K-Fold splits randomly, which can inadvertently create folds with unequal class representations. Stratified K-Fold ensures that every single fold maintains the identical percentage distribution of all 6 classes, eliminating evaluation bias."
Q6: Why did PCA require 102 components to capture 95% variance?
"Sir, high-frequency sensor streams contain minor noise across multiple axes. The first 102 orthogonal eigenvectors capture 95% of total signal energy while discarding the remaining 459 noisy components, reducing feature bandwidth by ~82% while keeping accuracy at 95.4%."
